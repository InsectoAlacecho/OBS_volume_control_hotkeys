OBS Volume Control Hotkeys


1- Download the script.

2- Add a "Gain" filter to the source whose volume you want to control. Make sure to remember the name you assign to the filter, as you will need it later.

3- Replace the placeholder in the first line of the script (PLACEHOLDER1) with the name of the source you want to control, and the placeholder in the second line (PLACEHOLDER2) with the name of the "Gain" filter you just added.

4- Go to Tools > Scripts, then click the "+" button to add and load the script.

5- Open Settings > Hotkeys, and assign keys for increasing, decreasing, and resetting the volume.
